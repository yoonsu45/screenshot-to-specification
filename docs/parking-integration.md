# 주차 안내 연동

`가는 길 → 자가용`에서 공연장별 공식 주차구역, 대체 후보와 지도 검색을 제공한다.
기존 시연용 행사 일정은 별도 영역으로 유지하며 실측값이나 예측 입력으로 사용하지 않는다.

## 서버 설정

로컬 `.env.local`과 배포 서버 Secrets에 다음 이름을 등록한다. 브라우저용 `VITE_` 접두사를 붙이지 않는다.

- `CULTURE_PARKING_FLOW_API_SERVICE_KEY`: 문화공공데이터 659, API_CPM_008
- `CULTURE_API_SERVICE_KEY`: 문화공공데이터 675, API_CPM_009
- `SEOUL_OPEN_DATA_API_KEY`: 서울 열린데이터광장 일반 인증키

로컬 환경변수를 바꾸면 개발 서버를 재시작한다. 로컬 키는 배포 서버로 복사되지 않는다.
서버 함수만 외부 API를 호출한다. 브라우저에는 정규화한 대수·기준시각·상태만 전달한다.
실시간 조회는 60초, 과거 자료는 5분 동안 프로세스 내 캐시하며 진행 중인 요청도 공유한다.
이 캐시는 서버 인스턴스 간 공유되지 않으므로 규모 확장 시 공유 캐시/수집 작업이 필요하다.

## 데이터 해석과 제한

- 실시간 API의 `parking_sum`은 동2/남2/북2문 제공 범위의 주차대수로만 표기한다. 잔여 대수로 해석하지 않는다.
- 원자료 측정 시각은 없으므로 서버 조회 시각을 표시한다. 오래된 캐시를 최신 현황으로 표시하지 않는다.
- 문화 API는 1페이지의 소량 기록만 조회한다. 전체 기간 통계, 최신 기록 또는 예측이라고 표시하지 않는다.
- `ISSUED_DATE`를 기준시각으로 사용한다. 수집일·등록일을 관측시각으로 대체하지 않는다.
- 확인한 675 응답은 페이지 제목과 달리 입출차 추가정보였다. `DESCRIPTION`에서 명시된 `주차대수`만 읽는다.
- 659가 입차/출차만 제공할 경우 초기 재차량 수 없이 차이를 현재 주차대수로 계산하지 않는다.
- 개별 주차장 식별자·실측 점유대수·동일 범위 총 주차면 수가 없어 현재 혼잡도와 예상 잔여 대수는 확인 불가다.
- 대체 구역은 공식 이용구역을 참고한 후보이며 실시간 빈자리, 영업 여부 또는 최단 거리 순위를 보장하지 않는다.
- 오류·점검·인증 실패·시간 초과 시 확인 불가로 표시한다. 빈 데이터나 오류를 0대로 대체하지 않는다.

공식 페이지 간 수용 대수·운영시간이 달라 고정 수용 대수로 혼잡률을 계산하지 않는다.
주차장별 실제 현황 피드와 검증된 수용량을 확보한 후 점유율·잔여 대수·혼잡 기반 대체 추천을 추가할 수 있다.

## 서울시 외부 대체 후보 연동

`GetParkingInfo` 공식 API를 별도 서버 함수로 조회한다. 공원 API 지연과 독립적으로 렌더링한다.
2026-11-16 실응답에서 확인한 신천유수지(173646), 천호역(173867), 잠실역(1277145),
성내역/잠실나루역(1475224)을 외부 대체 후보로 표시한다. 공연장별 근접 순위나 도보 경로를 주장하지 않는다.
전체 122개 응답 중 위 후보만 추출했고, 실제 운영 조회는 첫 1,000개 이내를 대상으로 한다.

- 공식 명세: https://data.seoul.go.kr/dataList/openApiView.do?infId=OA-21709&srvType=A
- 출처: https://data.seoul.go.kr/dataList/OA-21709/A/1/datasetView.do
- 공식 요청 주소는 `http://openapi.seoul.go.kr:8088`이다. 해당 포트의 HTTPS 조회는 실패했다.
- `TPKCT`는 총 주차면, `NOW_PRK_VHCL_CNT`는 현재 차량 수이며 차이로 잔여 대수를 계산한다.
- `NOW_PRK_VHCL_UPDT_TM`을 한국시간으로 해석한다. 수집 시각으로 대체하지 않는다.
- 연계 플래그가 1이고, 기준 시각이 20분 이내이며 정상 범위의 정수인 경우에만 잔여 대수를 표시한다.
- 총 면수보다 많은 현재 차량 수, 미연계, 오래된 자료를 0대/여유로 바꾸지 않는다.
- 혼잡도는 공식 등급이 아닌 서비스 점유율 기준이다: 70% 미만 여유, 70~90% 미만 보통,
  90% 이상 혼잡, 잔여 0대 만차. 도착 시점 예측이나 운영 중임을 보장하지 않는다.
- API 응답에는 좌표가 없어 거리 순위는 제공하지 않으며 지도에서 이동 경로와 운영시간을 확인한다.
- 인증키는 서버에서만 읽고 오류·요청 URL·응답 원문을 브라우저나 로그에 노출하지 않는다.
