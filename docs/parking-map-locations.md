# 공원 내부 주차장 지도 위치

2026-11-19 올림픽공원 공식 주차 안내와 네이버지도에 등록된 개별 장소를 대조했다.
광범위한 주차장 영역의 대표 위치이며 차량 진입구 위치와 다를 수 있다.

| 구역 | 네이버지도 장소 ID |
| --- | --- |
| P1A | 18880546 |
| P1B | 471925146 |
| P2 | 18878344 |
| P4 | 37049466 |
| P5 | 37049467 |
| P7 | 21893897 |

P6, 그래피티의 벽 주차장, 서1문 주차장 등은 정확한 위치를 대조하지 못해
추정 좌표로 표시하지 않고 공식 안내도로 연결한다. P2와 올림픽홀 지하주차장은
공식 안내에서 별도 선택지로 제공하므로 단일 P2 좌표에 두 이름을 합치지 않는다.
