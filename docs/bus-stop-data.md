# 주변 버스 정류장 자료

서울시 제공 `서울시버스정류소위치정보(20260902).xlsx`와
`서울시버스노선별정류소정보(20260902).xlsx`를 정류소 NODE_ID로 연결했다.
공원 주변 정류장 중 서울시 노선 자료와 연결되는 항목만 추출한다. 경기 등
서울시 자료에 없는 노선은 표시되지 않을 수 있으며 실시간 자료가 아니다.

`internalVenueProfiles`의 공연장 좌표와 정류장 좌표 사이의 직선거리 순으로
네 곳을 표시한다. 이 순서는 실제 도보거리나 출입 가능 경로를 뜻하지 않는다.
동일 이름 정류장이라도 방향에 따라 정류소 번호가 다르므로 구분해 표시한다.

원본 파일을 받은 뒤 재생성:

```powershell
python scripts/build_bus_stops.py '정류소 위치정보.xlsx 경로' '노선별 정류소정보.xlsx 경로'
```

자료를 갱신하면 화면의 기준 날짜도 함께 수정해야 한다. 원본 자료의 기준일,
좌표와 식별자 형식, 노선 누락 여부를 검토한다.
